# Vivian Conveyors — Alternate UI Theme

This ZIP contains the same 12-page Vivian Conveyors website, with the original page content, navigation, JavaScript interactions and supplied equipment images retained. The visual theme has been changed to a graphite, deep-teal and signal-lime industrial design system.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code Live Server.

The enquiry form remains a frontend demonstration and does not send/store enquiries without a backend or email service.
